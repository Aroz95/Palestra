# Illustrazioni degli esercizi

Le immagini di questa cartella (`*.webp`) provengono dal progetto **Everkinetic**, illustrazioni di Greg Priday:
<https://github.com/everkinetic/data>, sito originale <http://everkinetic.com>.

Licenza: **Creative Commons Attribuzione – Condividi allo stesso modo 4.0 Internazionale (CC BY-SA 4.0)**,
<https://creativecommons.org/licenses/by-sa/4.0/deed.it>.

Modifiche apportate: per ogni esercizio è stato scelto un solo fotogramma, ridimensionato (lato lungo 240 px), su
sfondo bianco, in scala di grigi e convertito in WebP. Le immagini modificate sono distribuite con la stessa licenza
CC BY-SA 4.0. La licenza riguarda solo queste immagini, non il resto dell'app.

Il file `manifest.json` indica per ogni immagine l'esercizio e il file originale Everkinetic da cui è ricavata.
Alcune corrispondenze sono approssimate perché il set non contiene la variante esatta (indicato nel manifest):
- `lat-machine`: Pull Down con presa inversa (stessa macchina, presa diversa);
- `row-machine`: rematore seduto ai cavi (movimento equivalente; il set non ha la macchina);
- `croci-cavi`: croci ai cavi su panca piana;
- `reverse-fly`: alzate posteriori da seduto ai cavi.

Non hanno illustrazione perché il set non le contiene: plank frontale, hip thrust, face pull.
